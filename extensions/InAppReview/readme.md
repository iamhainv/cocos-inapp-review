# InAppReview

Cocos Creator extension wrapping the native "rate this app" prompt:
Google Play In-App Review API on Android, `SKStoreReviewController` /
`AppStore.requestReview` on iOS.

- 中文: [doc/zh/index.md](./doc/zh/index.md)

- iOS specifics: [doc/en/ios/index.md](./doc/en/ios/index.md) · [doc/zh/ios/index.md](./doc/zh/ios/index.md)
